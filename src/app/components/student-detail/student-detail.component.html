How Route Parameters Work (Experiment 19)

When a user clicks on any student link like /student/{{ student.id }}:

  1. Angular Router matches the route definition: { path: 'student/:id', component: StudentDetailComponent }
  2. The component reads the parameter using ActivatedRoute.paramMap.subscribe(params => params.get('id'))
  3. It retrieves the corresponding student object from StudentService.getStudentById(id)
